# Google Apps Script 수신기 설정

앱이 보내는 JSON 을 Google 스프레드시트에 한 줄씩 기록합니다.
Claude 는 Google Drive 연동으로 이 시트를 읽습니다.

## 1. 스프레드시트와 스크립트 만들기

1. Google Drive 에서 새 스프레드시트를 만듭니다. (예: `카카오뱅크 알림기록`)
2. 메뉴 **확장 프로그램 > Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 내용을 붙여 넣고 저장합니다.
4. 왼쪽 **프로젝트 설정(톱니)** > **스크립트 속성** 에서
   - 속성: `SECRET`
   - 값: 앱 설정 화면의 **비밀키** (앱에서 "비밀키 복사" 사용)
   를 추가하고 저장합니다.
5. 편집기에서 `setupSheet` 함수를 한 번 실행해 권한을 승인합니다. (`알림기록` 시트와 헤더가 생성됩니다.)

## 2. 웹앱으로 배포

1. 오른쪽 위 **배포 > 새 배포** 를 누릅니다.
2. 유형: **웹 앱**
3. 실행 계정: **나**
4. 액세스 권한: **모든 사용자** (앱이 로그인 없이 POST 해야 하므로 필수. 비밀키로 접근을 제한합니다.)
5. 배포 후 표시되는 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다.

## 3. 앱에 입력

앱 **설정** 화면에서

- 웹훅 URL: 위 `exec` 주소
- 비밀키: 스크립트 속성 `SECRET` 과 동일
- **웹훅 전송 사용** 켜기 → **저장** → **테스트 전송**

"테스트 성공" 이 뜨면 시트에 `event=test` 행이 추가됩니다.

## 4. 주의

- 코드를 수정했다면 **배포 > 배포 관리 > 새 버전** 으로 다시 배포해야 반영됩니다.
- 시트에는 금융 거래 정보가 쌓입니다. 시트 공유 범위를 본인 계정으로 제한하세요.
- `dedupe_key` 열로 중복 기록을 막습니다. 열을 삭제하지 마세요.
