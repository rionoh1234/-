# 설계 문서 및 밸런스 수치

## 1. 배경 및 목표
- 참고 서비스(kickru.com)는 시즌 단위로 빠르게 넘어가는 구조라 몰입 시간이 짧음
- 목표: ① 시즌 중 멈춤 시점 확대(월 단위 10회 + 이적시장·결산) ② 집중 훈련·스킬 습득으로 육성 깊이 확보 ③ 경기 속 직접 선택
- 원칙: 참고 서비스의 코드·문구·이미지는 사용하지 않고 독자 구현

## 2. 시즌 타임라인 (월 인덱스)
| 월 | 내용 |
|---|---|
| 7월(0) | 프리시즌 캠프(성장 ×1.4), 친선경기 |
| 8월~5월(1~10) | 리그·컵·대륙대회, 매달 주요 경기 1개 직접 플레이 |
| 1월(6) | 겨울 이적시장 (제안이 있을 때만), 상무 전역 |
| 6월(11) | 시즌 결산 → 대표팀 대회 → 발롱도르 → 오프시즌 → 여름 이적시장 |

※ 단순화: 모든 리그를 8월~5월 일정으로 처리(K리그·J리그의 실제 춘추제와 다름), 승강제 없음.

## 3. 조정 가능한 핵심 수치 (확인 필요)
아래 값은 개발 중 자동 플레이 시뮬레이션으로 잡은 **임시값**입니다. 원하시는 게임 난이도에 맞춰 조정이 필요합니다.

| 항목 | 현재 값 | 위치 |
|---|---|---|
| 월간 성장 계수 | `GROWTH_K = 0.9` | src/engine.js |
| 집중 훈련 배분 비율 | `FOCUS_SHARE = 0.45` | src/engine.js |
| 훈련 강도별 성장/피로 | 0.75/1.0/1.2/1.4, 피로 -18/+2/+11/+20 | src/data.js `INTENSITY` |
| 스킬 레벨 비용 | Lv1 100 / Lv2 180 / Lv3 300 (월 기본 수련량 30) | src/data.js `SKILL_COST` |
| 스킬 보유 슬롯 | 6개 (약발 강화 제외) | src/data.js `SKILL_SLOTS` |
| 이벤트 발생 확률 | 월 72% + 부상 시 부상 이벤트 | src/engine.js `rollEvents` |
| 결정적 순간 수 | 선발 2회(중요도 8 이상 3회), 교체 1회 | src/engine.js `startFeatured` |
| 득점 기회 성공률 보정 | ×0.75 (페널티킥 제외) | src/engine.js `makeMoment` |
| 발롱도르 기준점 | 105 ± 8 | src/engine.js `computeBallon` |
| 은퇴 | 만 32세부터 선택, 만 40세 또는 만 35세 이상·OVR 60 미만 시 강제 | src/engine.js `offseason` |
