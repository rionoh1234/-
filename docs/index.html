기본 캐릭터 6종(등급별 1종)은 항상 보유하며, 뽑기 캐릭터는 같은 등급이라도 능력치가 20% 높고 더 강한 패시브를 가집니다. 게임 안에서는 보유한 캐릭터만 소환·합성됩니다.

모드 선택

스테이지는 40라운드 클리어 시 최초 1회 보석 보상(이후 재도전은 라운드 보상의 1/3). 무한 모드는 보석 50 + 라운드 × 15, 10라운드마다 디버프가 하나씩 추가되어 중첩됩니다.

출격 정보

규칙

  • 소환 20G · 같은 유닛 2개를 합쳐 상위 등급
  • 라운드마다 몬스터 20마리 · 10라운드마다 보스(45초 제한, 건너뛰기 불가)
  • 무한 모드: 10라운드마다 디버프 추가(중첩), 라운드 무제한
  • 살아있는 몬스터 80마리 이상이면 패배
  • 모든 캐릭터는 고유 패시브, 신화 등급만 자동 발동 스킬 보유
  • 조합식: 지정 재료 유닛을 보드에 모아 조합 전용 캐릭터 제작 (예: 검사×2 + 마법사×1 → 마검사)
  • 조합 전용 캐릭터는 전체 합성(C)에서 기본 제외 · 선택 패널/K 키로 유닛별 변경
  • 가장자리 칸일수록 길에 가깝습니다 (사거리 확인)
