# 랜타디 캐릭터 일러스트 제작 의뢰 (ChatGPT 이미지 생성용)

아래 내용을 그대로 ChatGPT에 붙여넣으면 됩니다. 한 번에 80종을 그리면 화풍이 흔들리므로 **등급별로 1장씩, 총 7장**(한 장에 최대 12캐릭터)으로 나눠 요청하는 구성입니다. 먼저 「공통 지시문」을 보내고, 이어서 「등급별 요청」을 하나씩 보내십시오.

---

## 1. 공통 지시문 (첫 메시지로 보내기)

```
당신은 2D 게임 스프라이트 디자이너입니다. 브라우저 랜덤 타워 디펜스 게임에 들어갈 캐릭터 아이콘을 만들어 주세요. 앞으로 등급별로 캐릭터 목록을 보낼 테니, 아래 규칙을 모든 그림에 동일하게 적용해 주세요.

[화풍]
- 16비트 JRPG 픽셀아트 느낌의 치비 캐릭터(2등신), 정면에서 약간 내려다본 3/4 시점, 굵고 어두운 외곽선, 색은 셀 셰이딩 2단계(기본색 + 그림자색)만 사용.
- 모든 캐릭터는 같은 크기, 같은 시점, 같은 조명으로 그립니다. 캐릭터는 셀 중앙에 서 있고, 몸 전체(머리부터 발까지)가 셀 안에 들어가야 합니다.
- 배경은 단색 밝은 회색(#E0E0E0) 평면으로, 그림자·바닥·장식·글자·테두리 효과를 넣지 않습니다. (나중에 배경을 투명 처리해 32×32 픽셀로 축소할 예정이므로 가는 선과 작은 디테일은 피하고, 실루엣과 색 대비가 뚜렷해야 합니다.)

[레이아웃]
- 한 장은 1024×1024, 가로 4칸 × 세로 3칸 = 12칸의 균등한 격자입니다. 칸 사이에는 1px 짙은 회색(#404040) 구분선을 넣어 주세요.
- 캐릭터는 내가 보내는 목록 순서대로 왼쪽 위에서 오른쪽으로, 그다음 줄로 배치합니다. 목록이 12개보다 적으면 남는 칸은 빈 회색 칸으로 둡니다.
- 칸 안에 이름이나 번호 같은 글자는 넣지 않습니다.

[등급 표현]
- 등급마다 정해진 포인트 색을 캐릭터의 망토·장식·무기 빛 등 한 군데에 반드시 넣어 등급이 구분되게 합니다.
  일반=회색(#AAB2BF), 고급=초록(#4CD27A), 희귀=파랑(#4AA3FF), 영웅=보라(#B16CFF), 전설=주황(#FF9F1C), 신화=빨강·금색(#FF4D6D), 특수=하늘색(#7EE8FA)
- 등급이 높을수록 장비가 화려하고 실루엣이 커 보이게(일반은 소박한 평민 장비, 신화·특수는 후광·불꽃·번개 같은 이펙트 1개 허용).

[각 캐릭터 설명의 읽는 법]
- "유형"은 공격 방식입니다. 단일 공격=활·총·창 같은 원거리 또는 날카로운 무기, 광역 공격=망치·도끼·폭탄·불, 연쇄 공격=번개·사슬·여러 개의 칼, 둔화=얼음·독·그물, 치명타=단검·사신 낫·저격.
- "패시브"와 "스킬"은 캐릭터의 성격을 드러내는 참고 자료입니다. 소품 1개 정도로 표현하면 충분합니다.
- "조합식"은 어떤 캐릭터를 합쳐 만드는지입니다. 재료 캐릭터의 색이나 장비 특징을 조금 이어받으면 좋습니다(필수는 아님).
- "현재 도트 참고"는 지금 게임에 있는 12×12 도트의 모자·무기·주색상입니다. 가능하면 같은 모자·무기·색 계열을 유지해 주세요.

이해했으면 "준비 완료"라고만 답해 주세요. 그러면 첫 번째 등급 목록을 보내겠습니다.
```
