# 조선 고봉밥 (Joseon Flavor Pack) — Victoria 3 모드

조선(KOR) 전용 역사 플레이버 모드입니다. 1836년 세도정치부터 대한제국 광무개혁까지, 조선 말기의 주요 사건을 저널·이벤트·결정으로 구현했습니다.

- 대상 게임 버전: **1.14 베타** (1.14.5 바닐라 데이터로 검증). 1.15 정식판(2026-10-22 예정)이 나오면 재검증이 필요합니다.
- 언어: 한국어 (영어 클라이언트용 대체 파일 포함, 아래 주의사항 참고)
- 접두어: `jfp_` (다른 모드와 충돌 방지)

## 설치

1. 저장소의 `joseon_flavor` 폴더를 통째로 아래 경로에 복사합니다.
   - Windows: `문서\Paradox Interactive\Victoria 3\mod\joseon_flavor`
2. Paradox 런처 → **플레이셋** → 모드 추가에서 `Joseon Flavor Pack (조선 고봉밥)`을 켭니다.
3. 게임 언어를 **한국어**로 설정하고, 조선으로 새 게임을 시작합니다.
   - 진행 중인 세이브에 넣어도 다음 달에 자동으로 초기화되지만, 이미 지난 연대의 사건은 발생하지 않습니다.

> ⚠️ 영어 클라이언트에서는 한글 글꼴이 없어 글자가 깨질 수 있습니다. 한국어로 플레이하세요.

### 대업(大業) 캠페인 — 어렵지만 보상이 큰 장기 목표

조선은 **청의 조공국**으로 시작합니다. 다섯 단계를 차례로 넘어야 하며, 각 단계에는 상시 불이익(역경)과 무작위 역경 이벤트가 붙습니다. 단계를 완료하면 **영구(약 200년) 보상**을 받습니다.

| 단계 | 완료 조건 | 진행 중 역경 | 완료 보상 (누적) |
|---|---|---|---|
| 1 자주독립 | 어떤 나라의 속국도 아님 (결정 '자주 선언'으로 독립 분쟁 개시 가능) | 위신 -10% | 위신 +20%, 정통성 +10, 권위 +15%, 사기 회복 +10% |
| 2 부국강병 | 열강 인정(recognized), 주요 강국 이상, 철도·민족주의·참모본부 기술, **일본보다 GDP와 육군 전력이 모두 높음** | 대출 이자 +15% | 기술 확산 +20%, 혁신 +20%, 관료 +15%, 건설 +15%, 공격·방어 +10%, **만주 전역 영유권 주장** |
| 3 고토 회복 | 한반도 5개 주 + 만주 핵심 4개 주(성경·남부 길림·북부 길림·남부 흑룡강) 확보 | 생활수준 -0.5 | 권위 +15%, 정통성 +10, 동화·편입 속도 +50%, **만주 전역이 조선인 고향 땅** |
| 4 동아시아의 패자 | 열강(great power), 세력권 맹주, **청과 일본이 속국이거나 같은 세력권** | 악명 증가 +25%, 영향력 -10% | 위신·영향력 +25%, 공격 +10%, 경험치 +25% |
| 5 대동아 공영권 | 동아시아·동남아시아의 모든 나라가 공영권 안, **동아시아에 공영권 밖 나라의 주가 없음** | 관료 -5%, 운동 급진화 +10% | 위신·영향력 +50%, 권위·관료·기술 확산 +25%, 전 건물 생산성 +10%, 공격·방어 +15%, 정통성 +15, 세력권 결속 +50% |

- 4단계에서 결정 **'대동아 공영권 결성'**으로 조선을 맹주로 하는 세력권을 만들 수 있습니다 (열강 필요). 세력권 이름은 `jfp_campaign_l_korean.yml`의 `jfp_pb_daedonga` 한 줄로 바꿀 수 있습니다.
- 2~5단계 도중 자주권을 잃으면 되찾을 때까지 그 단계를 완료할 수 없습니다. 청과의 조공 관계는 자주권 상실로 보지 않습니다.
- 캠페인 결정은 AI가 사용하지 않습니다.

### 연대기 이벤트 (날짜 도달 시 1회)

1836 다산 정약용 서거 · 1836 최한기 『기측체의』 · 1837 프랑스 신부 잠입 · 1839 기해박해 · 1841 아편전쟁 소식 · 1844 「세한도」 · 1845 사마랑호 · 1846 김대건 신부 · 1849 강화도령 · 1859 괴질 · 1860 북경 함락 소식 · 1861 「대동여지도」 · 1862 임술농민봉기 · 1864 흥선대원군 집권 · 1865 판소리 여섯 마당 · 1866 병인박해 · 1866 제너럴셔먼호 · 1866 병인양요 · 1868 오페르트 도굴 사건 · 1871 신미양요 · 1876 강화도 조약 · 1880 수신사 · 1881 영남만인소 · 1882 임오군란 · 1884 갑신정변 · 1885 거문도 사건 · 1889 방곡령 · 1894 『동의수세보원』 · (대한제국 이후) 독립협회, 대한국 국제

## 밸런스 수치

모든 수치는 v0.1 잠정값입니다.

- **수정자 효과**: `joseon_flavor/common/static_modifiers/jfp_modifiers.txt` 한 파일에 모여 있습니다.
- **진행도 증감폭** (+5/+10/+20/+25): `joseon_flavor/common/scripted_effects/jfp_effects.txt`
- **비용·급진/충성 인구·지속 기간**: 바닐라 기준값(`money_amount_multiplier_*`, `small_radicals` 등, `normal_modifier_time` = 5년)을 그대로 씁니다. GDP에 비례하므로 따로 조정할 필요가 없습니다.
- **저널 만료 기간**: `jfp_journal_entries.txt`의 `timeout` (일 단위)

## 검증 상태와 한계

- `tools/validate_mod.py`로 바닐라 1.14.5 기준 정적 검증을 통과했습니다 (오류 0, 경고 0).
  - 확인 항목: 중괄호 짝, 이벤트·저널·수정자 참조, 바닐라 수정자 타입 2,371종 대조, 스크립트 키워드 대조, 현지화 누락, BOM
- ⚠️ '동아시아' 지역에 러시아 극동이 포함되는지 확인하지 못했습니다. 포함된다면 5단계에서 러시아령까지 차지해야 합니다.
- **게임 내 실행 테스트는 아직 하지 않았습니다.** 정적 검증으로는 잡을 수 없는 문제(효과의 인자 형식, 툴팁 표시, 밸런스)가 있을 수 있습니다.
- 오류가 있으면 게임을 `-debug_mode` 옵션으로 실행한 뒤 `문서\Paradox Interactive\Victoria 3\logs\error.log`에서 `jfp`로 검색한 줄을 알려 주세요.

## 개발 도구

```bash
# 한국어 현지화에 BOM을 붙이고, 영어 대체 파일 생성
python3 tools/build_loc.py joseon_flavor

# 정적 검증 (참조 목록 없이도 동작, 있으면 바닐라 대조까지 수행)
python3 tools/validate_mod.py joseon_flavor \
    --modifier-types modifier_types.txt \
    --keywords effect_trigger_valid_keys.txt
```

참조 목록은 [Vic3TimelineExtended](https://github.com/jakeOmega/Vic3TimelineExtended) 저장소에서 만들 수 있습니다.

- `docs/engine/effect_trigger_valid_keys.txt`: 그대로 사용
- `vanilla_parsed/common/modifier_types.json`: 키 목록을 한 줄에 하나씩 뽑아 사용
