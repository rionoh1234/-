# 뱅크알림 기록 (BankNotiLogger)

안드로이드 폰에 수신되는 **카카오뱅크 앱 알림**을 실시간으로 감지해 폰 내부 DB에 기록하는 앱입니다.
1단계 범위는 "알림 인식 + 로컬 기록 + CSV 내보내기"이며, 외부 서버 전송 기능은 없습니다.

## 동작 방식

| 구성 | 역할 |
|---|---|
| `BankNotificationListener` | Android `NotificationListenerService`. 대상 앱 알림이 올라오면 제목·본문(펼친 본문 포함)·게시시각을 추출 |
| `NotificationParser` | 범용 규칙으로 구분(입금/출금/결제/취소/기타)·금액·잔액 추출. **원문은 항상 함께 저장** |
| `RecordDb` | SQLite. 같은 알림(키·게시시각·내용 동일)이 재전달되면 중복 저장하지 않음 |
| `MainActivity` | 권한 상태, 기록 목록(최근 500건), CSV 내보내기 |
| `SettingsActivity` | 수집 대상 패키지 편집, 최근 알림을 보낸 앱 목록, 테스트 모드, 전체 삭제 |

## 설치 (APK 받기)

1. GitHub 저장소 → **Actions** → `Build APK` 최신 실행 → 하단 **Artifacts**의 `bank-noti-logger-debug-apk` 다운로드(zip 안에 `app-debug.apk`)
2. 폰에서 APK 설치 (출처를 알 수 없는 앱 설치 허용 필요)
3. 앱 실행 → **알림 접근 권한 설정 열기** → `뱅크알림 기록` 허용

### ⚠️ Android 13 이상에서 권한 스위치가 회색으로 막혀 있을 때
스토어 외부에서 설치한 앱은 "제한된 설정"으로 알림 접근 권한이 차단됩니다.
**설정 → 애플리케이션 → 뱅크알림 기록 → 우측 상단 ⋮ → '제한된 설정 허용'** 후 다시 권한을 켜 주세요.
(메뉴 명칭은 제조사·OS 버전에 따라 다를 수 있음)

### ⚠️ 삼성 등 배터리 최적화
일부 제조사 기기는 백그라운드 앱을 종료해 알림 수집이 끊길 수 있습니다.
**설정 → 애플리케이션 → 뱅크알림 기록 → 배터리 → '제한 없음'** 으로 설정을 권장합니다.

## 첫 사용 시 확인 절차 (중요)

1. **카카오뱅크 패키지명 확인**: 기본 대상값 `com.kakaobank.channel`은 **확인 필요** 항목입니다.
   권한 허용 후 카카오뱅크 알림을 한 번 받은 다음, 설정 화면의 *최근 알림을 보낸 앱* 목록에서 카카오뱅크 항목의 패키지명을 확인하세요. 탭하면 대상에 추가됩니다.
2. **파이프라인 테스트**: 설정 → 테스트 모드 ON → *테스트 알림 보내기* → 메인 화면에 `[테스트] 입금 12,345원`이 기록되는지 확인. 확인 후 테스트 모드는 꺼 두세요.
3. **파싱 정확도 확인**: 실제 카카오뱅크 입·출금 알림 몇 건이 들어오면 목록의 구분·금액·잔액이 맞는지 원문과 대조하세요. 틀린 경우 원문(이름·계좌번호 가림)을 공유해 주시면 규칙을 보정합니다.

## 보안·개인정보

- `INTERNET` 권한이 **없습니다**. 수집 데이터는 기기 밖으로 전송되지 않습니다.
- 백업(`allowBackup`)·기기 이전 대상에서 DB를 제외했습니다.
- *최근 알림을 보낸 앱* 목록에는 다른 앱의 **패키지명과 시각만** 저장되며, 내용은 저장되지 않습니다.
- CSV 파일은 사용자가 지정한 위치에 저장되므로, 저장 후 관리 책임은 사용자에게 있습니다.

## 알려진 한계

- 알림 문구 형식이 확인되지 않아 금액·잔액은 `숫자+원`, `잔액 숫자원` 패턴만 인식합니다. 인식 실패 시 "금액 인식 안 됨"으로 표시되고 원문은 보존됩니다.
- 카카오뱅크 앱에서 알림을 끄거나, 폰의 알림 접근 권한이 해제되면 기록되지 않습니다.
- 권한 허용 이전·앱 삭제 상태에서 온 알림은 소급 수집되지 않습니다(서비스 재연결 시 화면에 남아 있는 알림만 회수).
- 실기기 검증은 아직 수행되지 않았습니다(단위 테스트·빌드·린트만 통과).
