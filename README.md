# ⚽ 풋볼 라이프 — 유스에서 레전드까지

16세 유스 선수로 시작해 프로 데뷔, 이적, 국가대표, 발롱도르, 은퇴까지 이어지는 **브라우저용 축구 커리어 시뮬레이션**입니다.
시즌을 한 번에 넘기지 않고 **월 단위(시즌당 10회 이상)로 멈춰서** 훈련·스킬·경기 속 선택을 직접 결정합니다.

## 실행 방법
- **권장: claude.ai Artifact 페이지** — https://claude.ai/artifact/C1uMjVnboHqZMVCDRBBbQr
  - 진행 내용이 claude.ai 계정 저장소에 자동 저장되어, 앱을 껐다 켜거나 다른 기기에서 열어도 이어집니다.
  - 엠블럼·국기가 페이지에 내장되어 있습니다.
  - 갱신: `python3 tools/embed-logos.py` → `node tools/build.js --artifact` → `dist/artifact.html` 을 같은 Artifact 주소로 다시 게시
- `index.html` 단일 파일: 브라우저로 직접 열어도 플레이할 수 있으나 저장은 그 브라우저(localStorage)에만 남습니다.
  미리보기 창처럼 저장소가 매번 초기화되는 환경에서는 저장이 유지되지 않습니다.

## 한 달의 흐름 (시즌당 7월~6월)
1. **월간 계획** — 집중 훈련(능력치 2개), 훈련 강도(4단계), 스킬 수련, 보조 활동(휴식·영상 분석·개인 트레이너 등)
2. **주요 경기 직접 플레이** — 결정적 순간 1~3회에 선택지 제시. 상황 40여 종(1대1, 리바운드, 오버헤드킥, PK 유도, 최후방 커버, 세리머니, 상대 도발, 하프타임 전술 등) 중 스코어·시간·체력·포지션에 맞춰 출제되며, 최근에 나온 상황은 덜 나옵니다. 성공률은 능력치·스킬·컨디션·상대 전력으로 계산하고, 스킬을 배우면 새 선택지가 열림
3. **이벤트** — 감독 면담, 부상 재활 방식, 경쟁자 영입, 포지션 변경, 에이전트, 상무 지원 등 (약 70% 확률)
   - ⏩ **자동 진행**: 같은 계획으로 이번 달만, 또는 1월/시즌 종료까지 한 번에 진행 (주요 경기 자동, 이벤트는 무난한 선택)
4. 1월·시즌 종료 후 **이적시장**, 6월 **시즌 결산·대표팀 대회·발롱도르 시상식**

## 주요 시스템
| 구분 | 내용 |
|---|---|
| 스킬 | 26종 × 최대 Lv3, 포지션·능력치 조건, 보유 슬롯 6개. 수련 중에는 능력치 성장 ×0.75 |
| 성장 | 나이·출전 비율·훈련 강도·시설·숨은 특성(성장 유형/프로 의식/부상 체질)·잠재력 격차 |
| 출전 | 오버롤·감독 신뢰·컨디션 vs 소속팀 전력 → 선발/교체/명단 제외(2군 경기) |
| 피로·부상 | 강훈련일수록 성장↑·피로↑·부상 위험↑, 재활 방식 선택 |
| 투자 | 장비 4종×3단계(일시 구매), 트레이너 4등급·영양사 3등급·주거 3단계(월 비용) |

| 다회차(레거시) | 은퇴 시 레거시 포인트(LP) 획득 → 잠재력 하한·시작 오버롤·성장·스킬·자금·부상 내성·약발·성장 유형 선택·시작 스킬 영구 강화 (9종) |
| 선수 생성 | 포지션·플레이 스타일만 선택, 잠재력은 숨겨진 채 무작위 (만 18세 스카우트 리포트로 공개) |
| 병역 | 대한민국 국적은 만 28세 전 김천 상무 복무(약 18개월). 아시안게임 금·올림픽 메달 시 특례 |
| 대회 | 14개 리그, 국내 컵, UEFA 챔피언스리그·AFC 챔피언스리그 엘리트·코파 리베르타도레스, 월드컵·유로·코파 아메리카·아시안컵·올림픽·아시안게임 |

## 엠블럼 · 국기
- 구단·대회 엠블럼은 TheSportsDB 이미지 주소(`src/logos.js`), 국기는 flagcdn.com을 **실행 시 인터넷에서 불러옵니다**. 이미지 파일 자체는 저장소에 포함하지 않습니다.
- 오프라인이거나 주소가 없는 구단(알 이티하드, 알 샤바브 등)은 이름 첫 글자 배지로 대체됩니다.
- 엠블럼 주소 다시 받기: `node tools/fetch-logos.js` → `node tools/fix-logos.js` → `node tools/build.js`

## 폴더 구조
```
index.html        ← 배포·플레이용 단일 파일 (빌드 결과물)
src/data.js       ← 리그·구단·스킬·훈련 옵션 데이터
src/engine.js     ← 게임 규칙 (DOM 없음)
src/ui.js         ← 화면
src/style.css, src/template.html
tools/build.js    ← src → index.html 합치기:  node tools/build.js
test/sim.js       ← 자동 플레이 밸런스 점검:  node test/sim.js 30 KOR ST
test/ui.js        ← 브라우저 클릭 테스트(Playwright)
docs/설계.md      ← 설계 및 조정 가능한 밸런스 수치
```

## 고지
개인 소장·플레이용 비공식 팬 게임입니다. 구단·리그·대회 명칭과 엠블럼의 권리는 각 권리자에게 있으며,
구단 전력·능력치·계약·이적료는 게임 밸런스용 가상 수치로 실제 평가와 무관합니다. 외부 공개·배포·수익화 시에는 권리 검토가 필요합니다.
