# ⚽ 풋볼 라이프 — 유스에서 레전드까지

16세 유스 선수로 시작해 프로 데뷔, 이적, 국가대표, 발롱도르, 은퇴까지 이어지는 **브라우저용 축구 커리어 시뮬레이션**입니다.
시즌을 한 번에 넘기지 않고 **월 단위(시즌당 10회 이상)로 멈춰서** 훈련·스킬·경기 속 선택을 직접 결정합니다.

## 실행 방법
- `index.html` 파일 하나를 브라우저(휴대폰 포함)로 열면 바로 플레이할 수 있습니다. 서버나 회원가입은 필요 없습니다.
- 진행 내용은 브라우저에 자동 저장되며, 메뉴에서 저장 파일을 내보내거나 가져올 수 있습니다.

## 한 달의 흐름 (시즌당 7월~6월)
1. **월간 계획** — 집중 훈련(능력치 2개), 훈련 강도(4단계), 스킬 수련, 보조 활동(휴식·영상 분석·개인 트레이너 등)
2. **주요 경기 직접 플레이** — 결정적 순간 1~3회에 선택지 제시. 성공률은 능력치·스킬·컨디션·상대 전력으로 계산하며, 스킬을 배우면 새 선택지가 열림
3. **이벤트** — 감독 면담, 부상 재활 방식, 경쟁자 영입, 포지션 변경, 에이전트, 상무 지원 등 (약 70% 확률)
4. 1월·시즌 종료 후 **이적시장**, 6월 **시즌 결산·대표팀 대회·발롱도르 시상식**

## 주요 시스템
| 구분 | 내용 |
|---|---|
| 스킬 | 26종 × 최대 Lv3, 포지션·능력치 조건, 보유 슬롯 6개. 수련 중에는 능력치 성장 ×0.75 |
| 성장 | 나이·출전 비율·훈련 강도·시설·숨은 특성(성장 유형/프로 의식/부상 체질)·잠재력 격차 |
| 출전 | 오버롤·감독 신뢰·컨디션 vs 소속팀 전력 → 선발/교체/명단 제외(2군 경기) |
| 피로·부상 | 강훈련일수록 성장↑·피로↑·부상 위험↑, 재활 방식 선택 |
| 병역 | 대한민국 국적은 만 28세 전 김천 상무 복무(약 18개월). 아시안게임 금·올림픽 메달 시 특례 |
| 대회 | 14개 리그, 국내 컵, UEFA 챔피언스리그·AFC 챔피언스리그 엘리트·코파 리베르타도레스, 월드컵·유로·코파 아메리카·아시안컵·올림픽·아시안게임 |

## 폴더 구조
```
index.html        ← 배포·플레이용 단일 파일 (빌드 결과물)
src/data.js       ← 리그·구단·스킬·훈련 옵션 데이터
src/engine.js     ← 게임 규칙 (DOM 없음)
src/ui.js         ← 화면
src/style.css, src/template.html
tools/build.js    ← src → index.html 합치기:  node tools/build.js
test/sim.js       ← 자동 플레이 밸런스 점검:  node test/sim.js 30 KOR ST
test/ui.js        ← 브라우저 클릭 테스트(Playwright)
docs/설계.md      ← 설계 및 조정 가능한 밸런스 수치
```

## 고지
구단·리그·대회 명칭은 게임 내 식별 목적의 텍스트로만 사용하며 로고는 사용하지 않습니다. 각 권리자와 제휴하지 않은 비공식 게임이며,
구단 전력·능력치·계약·이적료는 게임 밸런스용 가상 수치로 실제 평가와 무관합니다. 상업적으로 공개하기 전에는 명칭 사용에 대한 법률 검토가 필요합니다.
