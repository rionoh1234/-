# 랜타디 (Random Tower Defense) — 브라우저 프로토타입

스타크래프트 유즈맵 「랜덤 타워 디펜스(랜타디)」, 워크래프트3 「원피스 랜덤 디펜스(원랜디)」, 스타크래프트2 「랜덤 디펜스(스투랜디)」 장르의 핵심 규칙을 단일 HTML 파일로 구현한 프로토타입입니다.

## 실행
`docs/index.html` 을 브라우저로 열면 됩니다. 외부 의존성은 Google Fonts뿐입니다(없어도 동작).

## 조합식 균등화 (v0.11)
- 횃불병 → **용병**(범용 재료, 패시브 "잡기술"). 일반 8종이 조합식에 각각 **정확히 4회**씩 쓰이도록 재배치(기존 민병대 7회·횃불병 1회).
- 기본 갈래(사냥꾼 → 저격수 → 성기사 → 용기사 → 파멸자)는 일반 유닛만으로 항상 제작 가능하며, 시작 시 이를 자동 검증합니다.

## 조합 편의 패치 (v0.10)
- 보스 제한 시간 45초 → **90초**. 보스 등장 시 "일시정지 중에도 조합 가능" 안내 1회.
- **🎯 목표 조합 실행(G)**: 핀한 목표의 트리에서 중간 유닛별 필요 수량을 역산해, 보드 재료로 만들 수 있는 것을 낮은 등급부터 필요 수량만큼만 제작. 버튼을 누를 때만 1회 실행(배경 자동 없음). 트리 밖 유닛·🔒 잠금 유닛은 소비하지 않음. 결과 로그에 "소환으로 더 필요: 궁수×2" 표시.
- 유닛 클릭 시 선택 패널에 그 유닛이 재료인 조합 버튼이 바로 표시(⚒ = 지금 가능). 조합식 패널 기본 탭은 "지금 가능", 명령 카드에 "N 지금 조합 가능" 배지.
- 📌 핀 탭에 목표별 "지금 조합 가능 / 소환으로 더 필요" 표시. 조합식 행·조합 버튼에 마우스를 올리면(터치 유지) 재료 유닛 타일이 보드에서 깜빡임.

## 조합 트리 전환 (v0.9)
- 랜덤 소환은 **일반 8종**(전부 기본 보유)만 나옵니다. 행운 강화는 소환 시 고급 유닛이 바로 나올 확률(+5%/Lv, 최대 40%)로 변경.
- 같은 유닛 2개 합성 **삭제**. 상위 등급은 전부 **지정 조합식**으로만 제작: 고급 = 일반 2종, 희귀 = 고급 + 일반, 영웅 = 희귀 + 고급, 전설 = 영웅 + 희귀 + 일반, 신화 = 전설 + 영웅 + 희귀. 특수 8종은 기존 조합식 유지(총 48개 조합식, `RECIPES` 상수).
- 뽑기로 얻은 캐릭터는 조합식이 해금되며, 재료 캐릭터까지 보유해야 실제 제작 가능. 기본 갈래(사냥꾼 → 저격수 → 성기사 → 용기사 → 파멸자)는 항상 열림.
- 조합식 패널: 전체 / 지금 가능 / 📌 핀 / 등급별 탭. **자동 조합은 없음**(조합 버튼으로만 제작). 📌 핀은 목표 표시이며, 핀한 조합식의 하위 조합식 전체가 함께 핀되고 필요한 일반 유닛 총량이 표시됨. 🔒 잠금 유닛은 조합 재료로 쓰이지 않음.
- 시간 정지 재설계: 3초 동안 라운드 타이머·몬스터 이동·스폰이 멈추고 아군만 공격. 시간 연장 삭제, 중첩 시 남은 정지 시간만 3초로 갱신.
- 뽑기 확률: 고급 45 · 희귀 25 · 영웅 15 · 전설 9 · 신화 6%.
- `#debug` 해시로 열면 `window.__rtd.give(이름)` 테스트 훅이 활성화됩니다(로컬 검증용).

## 피드백 패치 (v0.8)
- 보스 라운드: 보스 처치 즉시 다음 라운드로 진행(남은 시간 대기 없음).
- 게임 중 상단 정보창은 라운드·남은 시간·골드·몬스터만 표시(보석·모드·유닛 제거, 보석은 로비에서만).
- 오라 유닛(성기사·음유시인·기계공·성전사 등)은 인접 3×3 영역이 등급색으로 상시 표시되고 선택 시 진해짐. 버프를 받는 유닛은 타일 모서리에 ▲ 표시. 대주교(성역)는 보드 전체 테두리 표시.
- 스킬 연출: 시전 타일 플래시 + 스킬 이름 텍스트(광역은 보드 중앙 대형), 범위 스킬은 확산 링 + 화면 가장자리 플래시, 단일 대상 스킬은 굵은 궤적 + 폭발. 쿨다운 완료 시 바 깜빡임.

## 신화 획득 완화 (v0.7)
- 캐릭터 뽑기 확률: 일반 37% · 고급 27% · 희귀 15% · 영웅 10% · 전설 7% · **신화 4%** (기존 1%).
- **천장**: 30회 연속 신화 미출현 시 다음 뽑기 신화 확정(횟수 저장, 신화 출현 시 초기화).
- **10연차 보장**: 10회 중 영웅 이상 1개 보장.
- **신화 조각**: 하위 등급 중복 뽑기 시 조각 지급(일반 1 · 고급 2 · 희귀 4 · 영웅 8 · 전설 15). 60조각으로 원하는 신화 캐릭터 선택(NEW 또는 ★+1). 보석 환급은 신화 ★MAX 중복(100보석)에만 적용.

## 성장 체계 개편 (v0.6)
- 게임 내 "등급별 공격력 강화" 삭제. 성장은 **뽑기 중복**으로만 이루어집니다.
- **신화 캐릭터**: 중복 뽑기마다 ★+1 (공격력 +15%/★, 최대 ★10, 초과 시 100보석 환급). 그 외 등급 중복은 보석 환급(일반 10 · 고급 15 · 희귀 25 · 영웅 40 · 전설 60).
- **전설 장비**: 같은 슬롯·옵션 중복 시 ★+1 (효과 +20%/★, 최대 ★10). 그 외 등급은 개별 아이템.
- 조합 전용 캐릭터는 **특수** 등급(7번째 등급)으로 분리: 상위 등급 합성 불가, 뽑기·소환·합성 결과에 등장하지 않음. 기존 등급 기준 공격력·판매가 유지.

## 조합식 (v0.5)
- 총 56종: 기본 6 + 뽑기 42 + **조합 전용 8**(마검사·성전사·설풍술사·황금기사·화염룡기사·대현자·암흑마검사·창조주).
- 조합 전용 캐릭터는 뽑기·소환·2개 합성 결과로 나오지 않고, 지정 재료 유닛을 보드에 모아 게임 패널의 "조합식"에서 제작합니다. 예: 검사×2 + 마법사×1 → 마검사.
- 재료 캐릭터를 모두 보유해야 조합식이 열립니다. 조합 전용 캐릭터는 전체 합성(C)에서 기본 제외됩니다. 일반 캐릭터는 기본 잠금 없음(K 키로 수동 잠금).
- 버그 수정: 소환 버튼 클릭 시 골드가 차감되지 않던 문제.

## 모드 (v0.4)
- **스테이지 1~4**: 40라운드 클리어 목표. 몬스터 체력 ×1 / ×1.7 / ×2.8 / ×4.5. 최초 클리어 시 1회 보석 보상(500 / 1,000 / 2,000 / 4,000), 재도전·실패 시 라운드 보상의 1/3. 이전 스테이지 클리어 시 다음 해금.
- **무한 모드(주 콘텐츠)**: 라운드 무제한. 10라운드마다(보스 라운드 시작 시) 디버프 10종 중 하나가 무작위로 추가되어 **중첩**됩니다(몬스터 체력·속도, 유닛 공격력·사거리, 골드, 라운드 시간, 몬스터 수, 보스 체력, 소환 비용, 몬스터 한계). 보석 50 + 라운드 × 15.
- **자동 합성 잠금**: 유닛별로 전체 합성(C) 제외 가능(선택 패널 또는 K 키). 조합 전용 캐릭터는 기본 잠금.

## 캐릭터 (v0.4)
- 총 42종: 등급별 **기본 1종** + **뽑기 6종**. 자동 발동 스킬은 **신화 등급 7종만** 보유.

## 캐릭터 (v0.3)
- 총 30종: 등급별 **기본 1종**(항상 보유, 능력치 ×1.0) + **뽑기 4종**(능력치 ×1.2, 더 강한 패시브).
- 모든 캐릭터는 고유 패시브 보유. 영웅·전설·신화는 쿨다운마다 자동 발동하는 스킬 보유(메테오, 빙결, 시간 정지, 용의 분노 등).
- 보스 라운드(10·20·30·40)는 "다음 라운드 바로 시작"이 비활성화됩니다.

## 메타 진행 (v0.2)
- 게임 종료 시 **보석 = 50 + 도달 라운드 × 15** (클리어 시 +300). 시작 보석 300.
- **캐릭터 뽑기** 100보석/회(10회 900): 일반 45%·고급 30%·희귀 14%·영웅 7%·전설 3%·신화 1%. 중복은 레벨 +1(공격력 +8%/Lv, 최대 Lv.10, 초과분 30보석 환급).
- **장비 뽑기** 100보석/회: 무기(공격력%)·신발(공격 속도%/사거리)·장신구(골드%/시작 행운/시작 골드), 희귀도 4단계. 슬롯별 1개 장착, 출격 유닛 전체에 적용.
- 게임 안에서는 **보유한 캐릭터만** 소환·합성 결과로 등장합니다. 상위 등급 캐릭터가 없으면 그 등급으로 합성할 수 없습니다.
- 캐릭터·몬스터·보스는 12×12 / 8×8 도트 스프라이트(코드 내 문자열 데이터)로 렌더링됩니다.
- 진행 상황은 브라우저 localStorage(`rtd_meta`)에 저장됩니다. 브라우저·기기별로 따로 저장됩니다.

## 인게임 규칙
| 항목 | 값 | 출처 장르 |
|---|---|---|
| 소환 비용 | 20G, 등급 6단계(일반·고급·희귀·영웅·전설·신화) | 공통 |
| 합성 | 같은 유닛 2개 → 상위 등급 무작위 유닛 | 랜타디(같은 티어 같은 타워 2개) |
| 라운드 | 총 40, 라운드당 몬스터 20마리, 25초 | 랜타디(40라운드) |
| 보스 | 10·20·30라운드, 40라운드 최종 보스, 45초 제한 | 랜타디 + 스투랜디(시간 제한) |
| 패배 | 살아있는 몬스터 80마리 이상 / 보스 시간 초과 | 원랜디(데스카운트) |
| 강화 | 등급별 공격력 +12%/Lv, 행운 강화(상위 등급 확률 상승) | 공통 |

몬스터는 외곽 길을 계속 돌며, 유닛은 가장자리 칸일수록 길에 가깝습니다. 밸런스 수치는 `docs/index.html` 상단 `CFG` 블록에 모여 있습니다.

## 조작
S 소환 · C 전체 합성 · L 행운 강화 · N 다음 라운드 · Space 일시정지 · Esc 선택 해제. 유닛 클릭 후 빈 칸 클릭 시 이동.
