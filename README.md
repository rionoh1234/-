# 랜타디 (Random Tower Defense) — 브라우저 프로토타입

스타크래프트 유즈맵 「랜덤 타워 디펜스(랜타디)」, 워크래프트3 「원피스 랜덤 디펜스(원랜디)」, 스타크래프트2 「랜덤 디펜스(스투랜디)」 장르의 핵심 규칙을 단일 HTML 파일로 구현한 프로토타입입니다.

## 실행
`docs/index.html` 을 브라우저로 열면 됩니다. 외부 의존성은 Google Fonts뿐입니다(없어도 동작).

## 캐릭터 (v0.3)
- 총 30종: 등급별 **기본 1종**(항상 보유, 능력치 ×1.0) + **뽑기 4종**(능력치 ×1.2, 더 강한 패시브).
- 모든 캐릭터는 고유 패시브 보유. 영웅·전설·신화는 쿨다운마다 자동 발동하는 스킬 보유(메테오, 빙결, 시간 정지, 용의 분노 등).
- 보스 라운드(10·20·30·40)는 "다음 라운드 바로 시작"이 비활성화됩니다.

## 메타 진행 (v0.2)
- 게임 종료 시 **보석 = 50 + 도달 라운드 × 15** (클리어 시 +300). 시작 보석 300.
- **캐릭터 뽑기** 100보석/회(10회 900): 일반 45%·고급 30%·희귀 14%·영웅 7%·전설 3%·신화 1%. 중복은 레벨 +1(공격력 +8%/Lv, 최대 Lv.10, 초과분 30보석 환급).
- **장비 뽑기** 100보석/회: 무기(공격력%)·신발(공격 속도%/사거리)·장신구(골드%/시작 행운/시작 골드), 희귀도 4단계. 슬롯별 1개 장착, 출격 유닛 전체에 적용.
- 게임 안에서는 **보유한 캐릭터만** 소환·합성 결과로 등장합니다. 상위 등급 캐릭터가 없으면 그 등급으로 합성할 수 없습니다.
- 캐릭터·몬스터·보스는 12×12 / 8×8 도트 스프라이트(코드 내 문자열 데이터)로 렌더링됩니다.
- 진행 상황은 브라우저 localStorage(`rtd_meta`)에 저장됩니다. 브라우저·기기별로 따로 저장됩니다.

## 인게임 규칙
| 항목 | 값 | 출처 장르 |
|---|---|---|
| 소환 비용 | 20G, 등급 6단계(일반·고급·희귀·영웅·전설·신화) | 공통 |
| 합성 | 같은 유닛 2개 → 상위 등급 무작위 유닛 | 랜타디(같은 티어 같은 타워 2개) |
| 라운드 | 총 40, 라운드당 몬스터 20마리, 25초 | 랜타디(40라운드) |
| 보스 | 10·20·30라운드, 40라운드 최종 보스, 45초 제한 | 랜타디 + 스투랜디(시간 제한) |
| 패배 | 살아있는 몬스터 80마리 이상 / 보스 시간 초과 | 원랜디(데스카운트) |
| 강화 | 등급별 공격력 +12%/Lv, 행운 강화(상위 등급 확률 상승) | 공통 |

몬스터는 외곽 길을 계속 돌며, 유닛은 가장자리 칸일수록 길에 가깝습니다. 밸런스 수치는 `docs/index.html` 상단 `CFG` 블록에 모여 있습니다.

## 조작
S 소환 · C 전체 합성 · L 행운 강화 · N 다음 라운드 · Space 일시정지 · Esc 선택 해제. 유닛 클릭 후 빈 칸 클릭 시 이동.
